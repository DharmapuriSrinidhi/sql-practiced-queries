# sql-practiced-queries

## Introduction
A collection of core SQL practice queries written as part of my SQL practice using o-list e-commerce datasets and istudio hands on project dataset and result sheets.

The queries focus on fundamental SQL operations used to retrieve, filter, sort, and analyse structured data.

## Objectives

- Practised writing SQL queries using different tables.
- Retrieve specific columns and filter records based on conditions.
- Sort and limit query results.
- Perform basic data aggregation and grouping.
- Strengthen SQL fundamentals for data analytics.

## SQL Concepts Covered

- SELECT
- WHERE
- AND
- ORDER BY
- LIMIT
- LIKE
- COUNT()
- GROUP BY
- DISTINCT
